表格能被读取不等于可以预测。只有能映射到当前模型通道的文件才会生成寿命区间；无法映射的数据会逐文件说明原因，不会替换成未经核验的预测。

为什么不能把任意表格直接交给模型树模型对列的含义、顺序、窗口长度和时间分箱都敏感。

服务端会先识别布局、映射字段、核对单位和时间、排序并构造连续窗口，最后检查数据形状；确认一致后才运行 PyTorch 模型及其统计预测模块。增加无关列不会改变模型；如缺少必需通道、存在时间断档、单位倍率不明或语义无法消歧，系统会逐文件给出补充或修正指引，并在信息完整前暂不生成预测，不会复制已有通道或按列位置猜测。

电池部件（储能系统）60 个循环 × 4 个规范通道树专家：52 个统计特征 · PyTorch：55 个直接特征

因此，“文件能读取”只表示表格结构可解析；“生成预测”还必须满足组件、字段、单位、时间轴、历史长度和最终维度全部一致。未知数值列会保留在诊断中但不参与模型，未来标签和未声明派生量永不进入推理。

支持范围与校验准则

先确认文件能唯一映射为遥测时序语义，再提交预测。这里的说明只描述当前服务端实际接受的边界。

支持的文件与校验原则正在读取服务端输入说明

提交长表或宽表：长表每行是一条观测，宽表每行是一个时间点。两者都必须由表头唯一识别，宽表会在服务端转换为统一的时间、遥测量、值记录，不会按列位置或数值形状猜测。

  • 两种输入布局长表为时间、遥测量、值；宽表为时间加一个或多个遥测通道列。
  • 时序接入与预测一项或有限多项数值通道可按长表或宽表结构读取；结构化接入不等于当前即可预测。只有能映射到当前模型通道的文件才会生成寿命区间，未映射数据会逐文件说明原因，不替换为泛化预测。
  • 预测输入与数据集文档当前预测可不带未来标签；用于复现、发布或长期维护的数据集还必须表达单位、组件或工况标识、退化状态或寿命标签，并配套数据字典。已声明模型通道的单位参与一致性校验，但单位本身不是模型特征。
  • 表头与列序按表头语义识别，不按位置猜测；未知数值通道会明确列为未参与模型。遇到重复通道或混合布局时，系统会说明需要整理的内容，并在整理完成前暂不生成预测。
  • 文本编码UTF-8 或 GB18030。
表头、时间单位与写法
时间 / time

推荐精确写成 cycle、time_ms、time_s、time_min、time_h、time_day 或 time_bin。普通 time 不带单位，必须在文件行手动选择。

遥测量 / telemetry

长表也可写 channel、signal、metric、遥测量(telemetry)。宽表则把下方已声明通道名直接作为列名。

值 / value

也可写 reading、measurement、值(value)。每个值必须是有限数值，不能是 NaN 或 Inf。

cycle循环序号：第几次循环time_ms相对时间，单位毫秒time_s相对时间，单位秒time_min相对时间，单位分钟time_h相对时间，单位小时time_day相对时间，单位天time_bin已聚合时间桶索引，不是秒或天

同时接受 time(s)、time[s]、时间（秒）、时间[秒]、时间_秒 等受控写法，全角括号会按同义符号处理；不会把 times 猜成 time_s。time_bin 表示“先把固定时长内的观测按服务端规则汇总，再用 0、1、2… 标记第几个桶”，它不能直接换算成秒、分钟或天。宽表和长表使用同一时间表头规则。

可选上下文字段与物理含义
orbit_altitude_km轨道高度 km：当前点或圆轨道的地心高度，即地心距离减去 6378.1363 km 地球赤道参考半径。
orbit_inclination_deg轨道倾角 deg：轨道平面与地球赤道平面的夹角，范围 0 至 180 度。
orbital_period_min轨道周期 min：完成一整圈轨道公转所需时间。
orbit_perigee_altitude_km近地点高度 km：椭圆轨道离地球最近点的地心高度，必须不小于任务边界 120 km。
orbit_apogee_altitude_km远地点高度 km：椭圆轨道离地球最远点的地心高度，不能小于近地点高度。
orbit_eccentricity偏心率 e：0 表示圆轨道，0<e<1 表示闭合椭圆，e=1 表示抛物线，e>1 表示双曲线。
orbit_semi_major_axis_km轨道半长轴 a（km）：由原始根数提供时优先使用，不从缺失字段反推。
orbit_speed_km_s当前切向速度 km/s：与高度一起用于比机械能和逃逸速度检查。
orbit_raan_deg升交点赤经 deg：参考赤道面上的轨道定向角。
orbit_arg_periapsis_deg近地点幅角 deg：升交点到近地点的轨道面内角度。
orbit_true_anomaly_deg真近点角 deg：当前点相对于近地点的轨道面内角度。
operating_condition原数据提供的运行工况标识或标量。
degradation_state原数据提供的退化状态或标量。
rul原数据提供的剩余寿命真值，仅用于溯源或后续离线评价，不是当前预测特征。
life_label原数据提供的寿命阶段或寿命真值标签，仅用于溯源或后续离线评价。
failure_label原数据提供的失效标签，仅用于溯源或后续离线评价。

这些上下文字段对当前预测请求可省略，缺失不会阻塞推理；用于复现、发布或长期维护的数据集仍必须表达单位、组件或工况标识、退化状态或寿命标签，并随数据字典说明来源与生成依据。当前已核验模型未声明这些输入，因此只用于回放与溯源，上传接口不执行逐时标签评价，也不会由页面补造。派生遥测只有在来源、计算/测量链、预测时可获得性、采样特性和退化关系可追溯且被模型明确支持时，才可能进入未来模型；标签和未来信息永远不进入当前预测。轨道参数不足或物理状态无法判定时，二维和三维轨迹均显示“未指定，不绘制轨迹”。
